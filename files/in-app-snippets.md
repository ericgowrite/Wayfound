# In-App Legal Text Snippets

Use these snippets in the app UI.

---

## Footer (Always Visible)

### Short Version (Recommended)
```
ViyaWay may earn a commission from bookings. This doesn't affect our recommendations. 
Privacy Policy | Terms of Service | How We Make Money
```

### Minimal Version
```
Privacy | Terms | Affiliate Disclosure
```

---

## Result Card Affiliate Label

When showing affiliate booking links on result cards:

```
Book on Booking.com →
```

Or with subtle disclosure:

```
Book on Booking.com → (affiliate link)
```

---

## Settings Page Links

Add a "Legal" section in Settings:

```
LEGAL
─────────────────────
Privacy Policy →
Terms of Service →  
How We Make Money →
```

## First-Time Affiliate Notice (Optional)

Show once when user first clicks an affiliate link:

```
┌─────────────────────────────────────────────────┐
│  Heads up                                       │
│                                                 │
│  This link takes you to [Partner Name].         │
│  If you book, we may earn a small commission    │
│  at no extra cost to you.                       │
│                                                 │
│  This doesn't affect our recommendations —      │
│  we show you what fits, not what pays.          │
│                                                 │
│  [Got it]  [Don't show again]                   │
└─────────────────────────────────────────────────┘
```
